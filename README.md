# Лендинг Shalun 2

Промо-страница рации Shalun 2. Отдельная папка, к приложению и серверу
отношения не имеет: только статические файлы.

## Где опубликовано

https://kelf2009-801.github.io/shalun2-landing/

Публикация идёт из ветки `gh-pages` репозитория `kelf2009-801/shalun2-landing`.
Файлы из этой папки копируются в корень той ветки. Боевой сервер рации
при этом не затрагивается.

## Запуск локально

Из этой папки:

```powershell
& "C:\Users\kelf2\AppData\Local\Programs\Python\Python313\python.exe" -m http.server 8080
```

Затем открыть `http://localhost:8080`.

Почему с полным путём: в Windows команда `python` по умолчанию ведёт на
заглушку Microsoft Store и ничего не запускает.

Почему не двойной клик по `index.html`: при открытии файлом браузер иначе
работает со шрифтами и частью поведения, чем на реальном хостинге.

## Структура

```
index.html              разметка, SEO, разметка для поиска
assets/css/tokens.css   цвета, шкалы, типографика — один источник
assets/css/base.css     сброс, примитивы, доступность
assets/css/sections.css секции и адаптив
assets/css/motion.css   анимации, hover-состояния, появление секций
assets/css/demo.css     интерактивная демонстрация передачи
assets/js/ui.js         мобильное меню, появление секций
assets/js/demo.js       логика демонстрации передачи
assets/img/             реальные скриншоты приложения
favicon.svg             знак
DESIGN.md               арт-дирекшн и решения
```

## Что менять где

| Задача | Файл |
|---|---|
| Цвет, отступ, размер шрифта | `assets/css/tokens.css` |
| Текст секции | `index.html` |
| Порядок секций | `index.html` |
| Точки адаптива | `assets/css/sections.css`, блоки `@media` |
| Анимации и hover | `assets/css/motion.css` |
| Демонстрация передачи | `assets/css/demo.css`, `assets/js/demo.js` |
| Появление секций | `assets/js/ui.js` |

Значения в секциях не задаются числами напрямую: только через токены.
Иначе одна и та же цифра начнёт жить в трёх местах и разъедется.

## Ограничения, которые нельзя нарушать

- Обещать можно только то, что есть в приложении. Список ограничений
  в секции 9 — часть продукта, а не скромность.
- SOS не гарантирует доставку и не заменяет экстренные службы.
- Скриншоты — настоящие. Не подменять нарисованными интерфейсами.
- Ссылка скачивания ведёт на рабочий сервер `/app/download`.
